Part 1: Matrix Multiplication

Our first function advance_time_matvecmul represents an iteration of the update of the heat diffusion simulation.

def advance_time_matvecmul(A, u, epsilon):
    """
    Advances the simulation by one timestep, via matrix-vector multiplication
    Args:
        A: The 2d finite difference matrix, N^2 x N^2. 
        u: N x N grid state at timestep k.
        epsilon: stability constant.
    Returns:
        N x N Grid state at timestep k+1.
    """
    N = u.shape[0]
    u = u + epsilon * (A @ u.flatten()).reshape((N, N))

    return u

Now we will make the function get_A(N) which returns the finite difference matrix A to use in advance_time_matvecmul.

def get_A(N):
    '''
    Creates the finite difference matrix A
    Parameter: N (given in this case)
    Returns: the finite difference matrix A
    '''
    n = N * N
    diagonals = [-4 * np.ones(n), np.ones(n-1), np.ones(n-1), np.ones(n-N), np.ones(n-N)]
    diagonals[1][(N-1)::N] = 0
    diagonals[2][(N-1)::N] = 0
    A = np.diag(diagonals[0]) + np.diag(diagonals[1], 1) + np.diag(diagonals[2], -1) + np.diag(diagonals[3], N) + np.diag(diagonals[4], -N)
    
    return A

Part 2: Sparse Matrix in JAX

To make our simulation faster, we will stop wasting time computing large amounts of zeros in the A matrix. Using the batched coordinate format with JAX, we can make each update only take O(N^2) time.

First, we will jit the function advance_time_matvecmul.

jitted_advance = jax.jit(advance_time_matvecmul)

Then we will create a function to get the matrix A in a sparse format.

def get_sparse_A(N):
    '''
    Parameter: N (given in this case)
    Returns: A_sp_matrix, the matrix A in a sparse format (BCOO).
    '''
    n = N * N
    diagonals = [-4 * jnp.ones(n), jnp.ones(n-1), jnp.ones(n-1), jnp.ones(n-N), jnp.ones(n-N)]
    diagonals[1] = diagonals[1].at[(N-1)::N].set(0)
    diagonals[2] = diagonals[2].at[(N-1)::N].set(0)
    A = np.diag(diagonals[0]) + np.diag(diagonals[1], 1) + np.diag(diagonals[2], -1) + np.diag(diagonals[3], N) + np.diag(diagonals[4], -N)
    A_sp_matrix = sparse.BCOO.fromdense(A)

    return A_sp_matrix

Part 3: Direct Operation with Numpy

Now let’s make the advance_time function faster by using vectorized numpy operations.

def advance_time_numpy(u, epsilon):
    """
    Advances the simulation by one timestep, via vectorized numpy operations.
    Args:
        u: N x N grid state at timestep k.
        epsilon: stability constant.
    Returns:
        N x N Grid state at timestep k+1.
    """
    N = u.shape[0]
    
    # Pad the input array with zeros
    u_padded = np.pad(u, pad_width=1, mode='constant', constant_values=0)
    
    # Calculate the Laplacian using vectorized operations (approximating A @ u.flatten())
    u_xx = np.roll(u_padded, shift=1, axis=0) + np.roll(u_padded, shift=-1, axis=0) - 2 * u_padded
    u_yy = np.roll(u_padded, shift=1, axis=1) + np.roll(u_padded, shift=-1, axis=1) - 2 * u_padded
    laplacian = u_xx + u_yy
    
    # Update the grid state and remove the padding
    u_new = u + epsilon * laplacian[1:-1, 1:-1]  # Unpadding the grid state

    return u_new

Part 4: With JAX

Finally, let’s make the advance_time function even faster using JAX.

@jax.jit
def advance_time_jax(u, epsilon):
    """
    Advances the simulation by one timestep, via vectorized JAX operations.
    Args:
        u: N x N grid state at timestep k.
        epsilon: stability constant.
    Returns:
        N x N Grid state at timestep k+1.
    """
    N = u.shape[0]

    # Pad the input array with zeros
    u_padded = jnp.pad(u, pad_width=((1,1),(1,1)), mode='constant', constant_values=0)

    # Calculate the Laplacian using vectorized operations
    u_xx = jnp.roll(u_padded, shift=1, axis=0) + jnp.roll(u_padded, shift=-1, axis=0) - 2 * u_padded
    u_yy = jnp.roll(u_padded, shift=1, axis=1) + jnp.roll(u_padded, shift=-1, axis=1) - 2 * u_padded
    laplacian = u_xx + u_yy

    # Update the grid state and remove the padding
    u_new = u + epsilon * laplacian[1:-1, 1:-1]  # Unpadding the grid state

    return u_new

Conclusion:

As we can see from timing the various methods of modeling heat diffusion, the first method with matrix-vector multiplication is extremely slow. By using a sparse matrix with JAX, part 2 is more than 10 times faster than part 1. Next up, part 3 is more than 100 times faster than part 1 as it uses vectorized array operations instead of the matrix-vector multiplication. Finally, we can make things even faster by using JAX; as we can see, part 4 is more than twice as fast as part 3.

On the other hand, although parts 3 and 4 were much faster than 1 and 2, they were also harder to write and more confusing for me. I think the implementation of part 1 was pretty intuitive, and once we had part 1, part 2 was pretty simple as well. However, overall the methods in part 3 and 4 are definitely the better methods because of how much more efficient they are.
